# Preliminary risk assessment

| Hazard | Potential effect | Design control | Residual work |
| --- | --- | --- | --- |
| Wrong deck setup | Incorrect transfer or collision | Explicit deck map and pre-run checklist | Physical verification |
| Insufficient source volume | Air aspiration and wrong concentration | Manifest volume validation | Liquid-level detection |
| Cross-contamination | False analytical result | Fresh tips and separated waste | Carryover study |
| Incorrect sample mapping | Loss of traceability | Unique IDs, wells, and rows | Barcode/LIMS integration |
| Pipetting inaccuracy | Incorrect dilution | Defined liquid classes and mixing | Gravimetric qualification |
| Interrupted run | Partial plate | Run log and controlled stop | Recovery procedure |
| Uncontrolled change | Non-reproducible result | Git history and tagged releases | Formal change control |

This assessment is educational and must be reviewed by qualified laboratory,
engineering, safety, and quality personnel before any physical use.
